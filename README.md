# performance-check-task
*Программа для запуска и прогона тестов CPU/GPU в Black Myth: Wukong Benchmark Tool*

## Запуск
В данный момент поддерживается только OS Linux, причем необходимо предустановить в вашем пакетном менеджере: 
- `ydotool`, для макроса чтобы запустить бенчмарк когда мы уже в игре
- `mangohud`, для получения информации о загрузке CPU/GPU итд

**Запуск осуществялется командой:**
```
dotnet run
```

## Выбор настроек игры для разных сценариев
**Общие**:
- Апскейлинг отключен совсем

**CPU-check**:
- Разрешение опущено насколько это возможно, в том числе и *Super resolution*
- Рейтрейсинг отключен
- Качество текстур, эффектов и прочего выкручено вниз
- Вообще все настройки на минимальных, кроме `VegetationQuality` (чем больше травы тем больше объектов на сцене), `ShadowQuality` (спорно, потому что GPU тут тоже рисует), а также `ViewDistance` (чем больше объектов на сцене тем сильнее кушается процессор)

**GPU-check**:
- по сути все наоборот, `VegetationQuality`, `ShadowQuality` и `ViewDistance` на минималках, а остальные на максимуме
- Рейтрейсинг включен
- Разрешение поднято обратно

## Описание работы программы
- Сперва заменяется сам конфиг игры на один из предложенных в репозитории в папке `configs`
- Закрывается стим, чтобы он не помешал записи в его конфиги
- Создается конфиг для `MangoHUD`
- Затем в папке стима изменяется файл `localconfig.vdf`, а именно в аргументы запуска игры добавляется `mangohud %command%` для запуска игры с хуком
- Запускается игра `steam:://rungameid/<id>`
- После 30 секунд запускается макрос чтобы зайти в сам бенчмарк
- Еще через врея игра закрывается и мой скрипт обрабатывает вывод `MangoHUD`
- Выводится ответ в `output/log.txt`
